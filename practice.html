P01 / ĐỌC ĐỀ & XÁC ĐỊNH YÊU CẦU

Yêu cầu sản phẩm website EduShop (Desktop 1100px)

Xây dựng giao diện Desktop cố định cho website EduShop gồm 2 trang liên kết: Trang chủ (Home) và Trang Đăng nhập (Login). Không làm responsive, không JavaScript và không backend.

[A] Header / Logo (Flexbox) [B] Hero Banner (2 Cột) [C] Thanh tìm kiếm [D] Danh mục (Grid 3 Cột) [E] Khóa học (Grid 3 Cột) [F] Giới thiệu (Flexbox) [G] Thông báo [H] Footer (Flexbox) [I-L] Login Form (Căn giữa 440px)
🎯 Phương pháp thực hành thiết kế:

Xem mẫu → Phân tích bố cục → Vẽ từ trang trắng → Gán HTML/Class/Parent → Đối chiếu → Chỉnh sửa

Lưu ý sư phạm: Học sinh không vẽ tự do bằng bút như Paint. Bạn sẽ sử dụng các component có sẵn trong thư viện để lắp ghép thành khung wireframe hoàn chỉnh, tương tự như xây dựng bố cục bằng các khối lego kiến trúc.

BƯỚC 1 / QUAN SÁT BẢN VẼ MẪU CHUẨN

🖼️ Bản vẽ Wireframe mẫu chuẩn EduShop (Home & Login)

Trước khi bắt đầu dựng khung, hãy quan sát kỹ bản thiết kế mẫu để nắm rõ vị trí các vùng, phân bổ lưới cột và kích thước chiều rộng:

Hình 1 · Bản vẽ Wireframe Trang chủ EduShop (Home):
• Chiều rộng khung nội dung: 1100px (căn giữa margin: 0 auto).
• 8 Khu vực chính: (1) Site Header [Logo + Menu], (2) Hero Banner 2 cột, (3) Search Box, (4) Category Grid (3 cột), (5) Course Grid (3 cột), (6) About Section, (7) Notice Box, (8) Site Footer.
• Mẹo: Các khối tràn ngang viền màn hình (Header, Hero, About, Footer) cần đặt <div class="container"> bên trong.
Hình 2 · Bản vẽ Wireframe Trang Đăng nhập EduShop (Login):
• Toàn bộ màn hình: nền xanh nhạt body.login-page, căn giữa bằng Flexbox main.login-layout (min-height: 100vh).
• Khung đăng nhập: div.login-card cố định chiều rộng 440px, bo góc, nền trắng.
• Cấu trúc Form: (1) Logo EduShop + Tiêu đề H1, (2) Input Email/User, (3) Input Mật khẩu, (4) Checkbox Ghi nhớ tôi + Liên kết Quên mật khẩu, (5) Nút Đăng nhập 100% width, (6) Liên kết trở về trang chủ.

💡 Ví dụ mẫu: Học sinh thực sự vẽ phần Header như thế nào?

Trước khi vẽ toàn bộ trang, hãy cùng tìm hiểu 5 bước chuẩn để lắp ráp khu vực Header:

Bước 1 Quan sát wireframe mẫu

Mẫu Header gồm Header bao ngoài, Container ở trong chứa Logo (trái) và Menu/Login (phải). Trả lời: Nhóm nào nằm ngoài cùng? Logo và menu xếp ngang hay dọc?

Bước 2 Chọn component Header

Từ thư viện component, nhấp + Header / Logo để đưa khối Header vào Canvas ở đầu trang và định hình độ rộng toàn màn hình.

Bước 3 Thêm Container

Đưa khối Container vào bên trong Header để giới hạn nội dung 1100px và tự căn giữa hai bên bằng margin: 0 auto.

Bước 4 Thêm Logo & Navigation

Đặt Logo ở bên trái, Navigation ở bên phải. Khối cha dùng Flexbox với justify-content: space-between để đẩy hai nhóm về hai đầu.

Bước 5: Gán thẻ HTML, Class và thiết lập Parent (Phần tử cha) qua Inspector:
Đối tượng Thẻ HTML (Semantic) Class CSS Phần tử cha (Parent) Lý do thiết kế
Header header site-header Trang (Root) Thẻ ngữ nghĩa đầu trang, đổ nền tràn viền màn hình
Container div container header-content Header Khối gom nội dung giới hạn 1100px căn giữa, kích hoạt Flexbox
Logo a brand Container Liên kết về trang chủ chứa logo và tên thương hiệu EduShop
Menu nav main-nav Container Thẻ ngữ nghĩa gom các liên kết điều hướng chính

⚠️ Lưu ý cốt lõi: Việc đặt các khối nằm bên trong nhau trên bản vẽ và thiết lập Parent là hai thao tác cần được kiểm tra riêng. Không nên mặc định rằng chỉ cần kéo một hình chữ nhật đè lên hình khác là cây HTML đã được tạo đúng.

Thứ tự dựng Wireframe toàn bộ Home & Login (Vùng lớn trước, nhỏ sau)

Trang chủ (Home) — 8 Vùng:
  1. HEADER: Logo + Menu điều hướng (Flexbox)
  2. HERO: Tiêu đề, CTA + Ảnh banner 2 cột
  3. SEARCH: Tiêu đề + Ô tìm kiếm + Nút [Tìm kiếm]
  4. CATEGORY: 3 Thẻ danh mục (CSS Grid)
  5. COURSES: 3 Thẻ khóa học (Dựng 1 card rồi dùng Duplicate)
  6. ABOUT: Giới thiệu nền tảng + Hình minh họa
  7. NOTICE: Thông báo ưu đãi + Nút xem chi tiết
  8. FOOTER: Thông tin bản quyền & Liên hệ
Trang Đăng nhập (Login) — 3 Bước căn giữa:
  1. Bước 1 · Login Layout: main.login-layout căn giữa toàn màn hình (100vh flexbox).
  2. Bước 2 · Login Card: Hộp thẻ div.login-card cố định 440px ở chính giữa.
  3. Bước 3 · Login Form: Logo EduShop → Tiêu đề H1 → Biểu mẫu form.login-form (Email/User, Password, Ghi nhớ, Quên mk, Nút đăng nhập 100% width).

CHẶNG C · REFACTORING

P08–P09: So sánh CSS hai trang & Tách style.css Dùng chung

P08 / PHÂN TÍCH TRÙNG LẶP CSS

Bảng đối chiếu quy tắc CSS Chung vs Riêng

Đặt home.css và login.css cạnh nhau. Chỉ gộp những quy tắc thể hiện cùng một nguyên tắc thiết kế hoặc component tái sử dụng:

Quy tắc CSS Home Login Vị trí lưu trữ Giải thích lý do
* { box-sizing: border-box; } ✓ ✓ style.css (Chung) Reset Box Model nền tảng cho toàn bộ website.
body { font-family, color, margin } ✓ ✓ style.css (Chung) Typography và màu nền cơ sở của nhận diện thương hiệu.
.container { width: 1100px; margin: 0 auto; } ✓ — style.css (Chung) Class utility căn giữa giới hạn độ rộng cho các trang con.
.button { padding, border-radius, background } ✓ ✓ style.css (Chung) Thành phần nút bấm tái sử dụng trên toàn hệ thống.
.hero, .category-grid, .product-grid ✓ — home.css (Riêng) Bố cục và thành phần đặc thù chỉ trang chủ có.
.login-layout, .login-card, .login-form — ✓ login.css (Riêng) Bố cục căn giữa màn hình và hộp đăng nhập riêng của Login.
P09 — Thứ tự liên kết file CSS chuẩn:

CSS dùng chung (style.css) phải liên kết trước, file CSS riêng của trang (home.css hoặc login.css) liên kết sau để đảm bảo quy tắc kế thừa Cascade.

CHẶNG D · ĐÁNH GIÁ

P10: Kiểm thử Hồi quy & Phiếu Đánh giá Sản phẩm

P10 / KIỂM THỬ HỒI QUY

Quy trình kiểm thử hồi quy (Regression Test)

Mở đồng thời ảnh chụp baseline (khi hai trang còn chạy độc lập) và website hiện tại sau khi đã nạp style.css. Đảm bảo:

  1. Giao diện không bị xô lệch khoảng cách, kích thước hoặc font chữ.
  2. Các liên kết qua lại giữa Home và Login hoạt động bình thường (đường dẫn tương đối).
  3. Tất cả hình ảnh hiển thị tốt offline không bị lỗi đường dẫn.
  4. Không xuất hiện lỗi console hay lỗi cú pháp CSS.
