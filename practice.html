CHẶNG C · REFACTORING

P08–P09: So sánh CSS hai trang & Tách style.css Dùng chung

P08 / PHÂN TÍCH TRÙNG LẶP CSS

Bảng đối chiếu quy tắc CSS Chung vs Riêng

Đặt home.css và login.css cạnh nhau. Chỉ gộp những quy tắc thể hiện cùng một nguyên tắc thiết kế hoặc component tái sử dụng:

Quy tắc CSS Home Login Vị trí lưu trữ Giải thích lý do
* { box-sizing: border-box; } ✓ ✓ style.css (Chung) Reset Box Model nền tảng cho toàn bộ website.
body { font-family, color, margin } ✓ ✓ style.css (Chung) Typography và màu nền cơ sở của nhận diện thương hiệu.
.container { width: 1100px; margin: 0 auto; } ✓ — style.css (Chung) Class utility căn giữa giới hạn độ rộng cho các trang con.
.button { padding, border-radius, background } ✓ ✓ style.css (Chung) Thành phần nút bấm tái sử dụng trên toàn hệ thống.
.hero, .category-grid, .product-grid ✓ — home.css (Riêng) Bố cục và thành phần đặc thù chỉ trang chủ có.
.login-layout, .login-card, .login-form — ✓ login.css (Riêng) Bố cục căn giữa màn hình và hộp đăng nhập riêng của Login.
P09 — Thứ tự liên kết file CSS chuẩn:

CSS dùng chung (style.css) phải liên kết trước, file CSS riêng của trang (home.css hoặc login.css) liên kết sau để đảm bảo quy tắc kế thừa Cascade.

CHẶNG D · ĐÁNH GIÁ

P10: Kiểm thử Hồi quy & Phiếu Đánh giá Sản phẩm

P10 / KIỂM THỬ HỒI QUY

Quy trình kiểm thử hồi quy (Regression Test)

Mở đồng thời ảnh chụp baseline (khi hai trang còn chạy độc lập) và website hiện tại sau khi đã nạp style.css. Đảm bảo:

  1. Giao diện không bị xô lệch khoảng cách, kích thước hoặc font chữ.
  2. Các liên kết qua lại giữa Home và Login hoạt động bình thường (đường dẫn tương đối).
  3. Tất cả hình ảnh hiển thị tốt offline không bị lỗi đường dẫn.
  4. Không xuất hiện lỗi console hay lỗi cú pháp CSS.
