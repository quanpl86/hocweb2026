01 / TỔNG QUAN YÊU CẦU

Đề bài website EduShop

Xây dựng giao diện Desktop cho website học trực tuyến EduShop gồm 2 trang liên kết với nhau: Trang chủ (Home) và Trang Đăng nhập (Login). Không làm Responsive, JavaScript hay xác thực tài khoản thật.

[A] Header / Logo (Flexbox) [B] Hero Banner (2 Cột) [C] Thanh tìm kiếm [D] Danh mục (Grid 3 Cột) [E] Khóa học (Grid 3 Cột) [F] Giới thiệu (Flexbox) [G] Thông báo [H] Footer (Flexbox) [I-L] Login Form (Căn giữa 440px)
02 / TIẾN TRÌNH THỰC HÀNH

Quy trình thực hiện 4 giai đoạn

  1. Giai đoạn 1 – Thiết kế Wireframe & Phân rã cấu trúc: Dùng công cụ Wireframe Studio ở trên để xếp các khối chức năng, xác định thẻ HTML ngữ nghĩa và quan hệ cha–con. Tải ảnh wireframe về máy để nộp bài.
  2. Giai đoạn 2 – Dựng trang Home độc lập: Tạo index.html và home.css trong VS Code. Tự viết đầy đủ Header, Hero, Grid và Footer.
  3. Giai đoạn 3 – Dựng trang Login độc lập: Tạo login.html và login.css. Xử lý bố cục căn giữa toàn màn hình (100vh), hộp Login Card 440px và các trường nhập.
  4. Giai đoạn 4 – Phân tích CSS & Tái cấu trúc (Refactoring): Đặt home.css và login.css cạnh nhau. Nhận diện các quy tắc trùng lặp nền tảng (*, body, .button, .container), chuyển sang style.css dùng chung và kiểm tra lại cả hai trang.
03 / QUY TẮC CSS REFACTORING

Tiêu chí phân loại CSS Chung vs Riêng

Nguyên tắc: CSS giống nhau tình cờ (ví dụ cùng có padding: 40px) không nhất thiết phải gộp. Chỉ gộp khi nó thể hiện cùng một quy tắc nền tảng hoặc cùng một thành phần tái sử dụng.

  • Lưu vào style.css: * { box-sizing: border-box; }, kiểu chữ & màu nền body, bố cục .container (1100px), thành phần nút dùng chung .button.
  • Lưu vào home.css: Bố cục .hero, .hero-content, .search-section, lưới .category-grid, .product-grid, .about-section.
  • Lưu vào login.css: Bố cục .login-layout (100vh flex căn giữa), .login-card (440px), .login-form, và modifier class .login-button { width: 100%; }.
  • Thứ tự liên kết: style.css liên kết trước, CSS riêng của trang liên kết sau.
