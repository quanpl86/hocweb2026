03 / CÁCH LÀM

Gợi ý triển khai

  1. Tạo thư mục dự án, hai file index.html và login.html cùng file CSS.
  2. Dùng thẻ div để gom các khu vực nội dung có liên quan.
  3. Áp dụng Box Model để tạo khoảng cách giữa nội dung, viền và các khối.
  4. Dùng Flexbox cho header/navigation và CSS Grid cho danh mục, sản phẩm.
  5. Viết HTML form và dùng CSS định dạng trang đăng nhập.
  6. Mở hai trang trong trình duyệt, đối chiếu với checklist trước khi nộp.
