# Bài 01 — Dựng Home và Login từ số 0

**Người học:** chưa có kiến thức web. **Mục tiêu:** tạo đúng các khu vực Home (header, menu, banner, tìm kiếm, danh mục, nổi bật, giới thiệu, thông báo, footer) và form Login (username/email, password, ghi nhớ, quên mật khẩu, nút đăng nhập).

**Trình tự học:**
1. Đọc [bản hướng dẫn Markdown gồm 16 bước](HUONG_DAN.md): mỗi bước giải thích thuật ngữ, bối cảnh, cách thao tác, kết quả cần quan sát.
2. Xem [tài liệu HTML có hình minh họa](HUONG_DAN_CHI_TIET.html) trên trình duyệt.
3. Làm [đề bài với starter](../../../03-thuc-hanh/chuong-02/bai-01-home-login/README.md) trước khi xem đáp án.
4. Đối chiếu [website mẫu hoàn chỉnh](../../../04-code-mau/chuong-02/home-login/README.md).

**Giới hạn:** chỉ HTML/CSS, không responsive, không JavaScript hay backend. Tìm kiếm/đăng nhập chỉ là giao diện.
