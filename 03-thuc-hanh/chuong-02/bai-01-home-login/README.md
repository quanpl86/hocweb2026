# Bài tập 01 — Home và Login

Đọc [yêu cầu bài tập](DE_BAI.md), sau đó sửa các file trong `starter/` bằng VS Code. Đừng sao chép đáp án ngay.

**Quy trình:** tạo cấu trúc HTML → thêm header và menu → hero → tìm kiếm → danh mục/sản phẩm bằng Grid → giới thiệu và footer → form Login → CSS hoàn thiện → kiểm tra.

**Nộp bài:** source HTML/CSS và tài nguyên có thể mở offline, ảnh chụp Home/Login, bảng phân công đóng góp theo thành viên. Không yêu cầu backend/JS/responsive.
