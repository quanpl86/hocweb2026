# Bắt đầu học thiết kế website

**Cần có:** VS Code (hoặc phần mềm soạn thảo văn bản thuần), Chrome/Edge, thư mục dự án trên máy. Không cần cài server cho ví dụ tĩnh.

1. Tải repository qua nút **Code → Download ZIP**, giải nén hoặc dùng `git clone https://github.com/quanpl86/hocweb2026.git`.
2. Mở VS Code → File → Open Folder → chọn thư mục vừa tải.
3. Đọc lý thuyết và thao tác từng bước trong `02-bai-hoc/`, hoặc mở ngay **[Quy trình thiết kế giao diện từ số 0 & CSS Refactor](file:///f:/Projects/LearningWeb/00-huong-dan-bat-dau/QUY_TRINH_THIET_KE.html)** (khuyên dùng cho người mới bắt đầu).
4. Tự làm bài trong `03-thuc-hanh/` (trên cổng học tập `practice.html` có tích hợp sẵn công cụ vẽ Wireframe Studio và Code Viewer), **chưa xem `04-code-mau/`**.
5. Mở `index.html` bằng trình duyệt; lưu file và làm mới trang để xem thay đổi.
6. Đối chiếu mã mẫu, ghi lại lỗi sai và nội dung cần ôn tập.

**Từ vựng:** HTML = cấu trúc nội dung; CSS = định dạng/bố cục; Wireframe = bản vẽ phác thảo cấu trúc khung xương giao diện; CSS Refactor = tái cấu trúc và tách code trùng lặp thành style dùng chung; trình duyệt = phần mềm hiển thị HTML; đường dẫn tương đối = đường dẫn tính từ file hiện tại; repository = kho lưu mã/tài liệu có lịch sử phiên bản.

**Phạm vi:** chỉ thiết kế layout trang Home và Login, không responsive, không triển khai chức năng tìm kiếm/đăng nhập thật.
