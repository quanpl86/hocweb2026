# Code mẫu — DIV, Box Model, Flexbox, Grid

Mở `index.html` để quan sát Home và `login.html` để quan sát Login. Cả hai dùng chung `style.css` và chạy offline.

Bài luyện: đổi `.category-grid` từ ba cột sang hai cột; thay `gap`; thay `justify-content` của header; tăng `padding` cho thẻ sản phẩm. Lưu CSS và làm mới trình duyệt.
