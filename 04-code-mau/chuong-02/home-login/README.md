# Code mẫu hoàn chỉnh — Home và Login

Mở `index.html` bằng Chrome hoặc Edge; nhấp liên kết Đăng nhập để mở `login.html`. Tất cả CSS và tài nguyên nằm trong thư mục này, không cần server.

- `index.html`, `login.html`: cấu trúc HTML.
- `css/style.css`: định dạng chung.
- `css/home.css`: riêng trang Home.
- `css/login.css`: riêng trang Login.
- `assets/`: ảnh SVG được trang HTML sử dụng.

**Lưu ý:** đây là đáp án tham khảo, có thể khác đề tài từng nhóm. Không có xử lý tìm kiếm/đăng nhập, không responsive.
