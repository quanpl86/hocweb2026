# DIV – Box Model – Flexbox – CSS Grid

[Mở tài liệu tương tác offline](bon-khai-niem/HUONG_DAN_TUONG_TAC.html) sau khi tải repository; tài liệu có 4 mô phỏng, hình ảnh và bài luyện tập.

| Chủ đề | Cần hiểu | Áp dụng |
| --- | --- | --- |
| `div` | Thẻ chứa và quan hệ cha-con, `class` | Gom sản phẩm, nhóm ô nhập |
| Box Model | content, padding, border, margin, box-sizing | Thiết kế thẻ sản phẩm, form |
| Flexbox | display:flex, hướng, căn chỉnh, gap | Header, menu, thanh tìm kiếm |
| CSS Grid | columns, repeat, fr, gap, span | Danh mục và lưới sản phẩm |
