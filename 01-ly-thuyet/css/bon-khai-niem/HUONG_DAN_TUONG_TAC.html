HTML và CSS làm hai công việc khác nhau

HTML mô tả trang web có những thành phần nào và thứ tự xuất hiện. CSS quyết định vị trí, khoảng cách, kích thước và màu sắc của các thành phần đó.

Thuật ngữ nền tảng: Element (phần tử) là một thành phần HTML như <div>. Parent (cha) là phần tử bao bên ngoài. Child (con) là phần tử nằm bên trong phần tử cha. Class là tên dùng để chọn nhiều phần tử bằng CSS, viết class="ten" trong HTML và .ten trong CSS.

Cách dùng tài liệu: đọc thuật ngữ → xem sơ đồ → tích chọn thông số ở khu mô phỏng → tự gõ ví dụ code vào VS Code → mở file HTML trên trình duyệt để kiểm tra.

Chủ đề 01 · xây khung

Thẻ <div> là gì?

DIV viết tắt từ “division”: vùng chia/khối chứa mang tính tổng quát trong HTML. Nó thường dùng để gom các phần tử liên quan thành một nhóm để CSS dễ điều khiển.

Định nghĩa: <div> là phần tử chứa dạng block theo kiểu hiển thị mặc định của trình duyệt: nó bắt đầu trên dòng mới và thường chiếm toàn bộ chiều ngang khả dụng của vùng cha. DIV không mang ý nghĩa nội dung riêng như <nav> hay <footer>.

2. Gõ từng bước

  2. Trong <body> tạo một div có class container.
  3. Đặt 3 thẻ div class="item" vào bên trong. Lưu file và mở bằng Chrome/Edge. Ban đầu 3 ô xuống dòng.
  4. Thêm CSS cho .container và .item; sau đó thử thêm display: flex vào cha để nhìn sự thay đổi.
Ví dụ HTML – phần đặt trong <body>

</div>

Chủ đề 02 · khoảng cách và kích thước

CSS Box Model: mỗi phần tử là một chiếc hộp

Khi một khối “bị lệch”, “sát nhau”, “to hơn width đã đặt”, nguyên nhân thường nằm ở Box Model.

Box Model (mô hình hộp) gồm bốn lớp từ trong ra ngoài: content (nội dung) → padding (khoảng đệm bên trong) → border (đường viền) → margin (khoảng cách bên ngoài). Mỗi phần tử HTML có những khái niệm này, dù có thể đang bằng 0.

1. Nhìn sơ đồ bốn lớp

Thuật ngữHiểu đơn giảnKhi nào dùng?
width, heightChiều rộng/cao vùng được CSS xác địnhĐặt kích thước card, form
paddingKhoảng cách chữ đến viền hộpNút bấm, card cần “thoáng” bên trong
borderĐường viền bao hộpViền input, card, nút
marginKhoảng cách bên ngoài hộpTách hai khu vực khỏi nhau
box-sizingQuy tắc tính width/heightKiểm soát kích thước không bị phình

2. Ví dụ thực tế cho thẻ sản phẩm

HTML
<div class="product-card">
  <h3>Khóa học Python</h3>
  <p>Dành cho người mới.</p>
</div>
CSS
.product-card {
  width: 240px;             /* kích thước dự kiến */
  padding: 20px;            /* chữ cách viền 20px */
  border: 2px solid #2161bb;/* đường viền 2px */
  margin: 16px;             /* cách bên ngoài 16px */
  box-sizing: border-box;   /* width gồm cả padding, border */
}

Đọc quy tắc CSS: .product-card là selector (bộ chọn) dựa trên class. Bên trong { } là các khai báo dạng property: value; — ví dụ padding là thuộc tính, 20px là giá trị. px là đơn vị pixel CSS.

Chiều rộng hộp từ mép border trái đến mép border phải:

Công thức chuẩn: với box-sizing: content-box, chiều rộng từ mép border trái đến mép border phải = width + padding-left + padding-right + border-left + border-right. Margin nằm NGOÀI kích thước này. Với border-box, width đã gồm content + padding + border. Khi padding/border quá lớn, kích thước nội dung có thể co lại.
Ví dụ tính: width 240px, padding trái/phải 20px, border trái/phải 2px → content-box cho hộp ngoài rộng 284px; border-box cho hộp ngoài rộng 240px. Margin trái/phải 16px làm tổng không gian ngang liên quan đến hộp thành 316px hoặc 272px trong bối cảnh đơn giản, chưa tính các quy tắc bố cục khác.

4. Cách viết tắt margin/padding

CSS — quy tắc TRBL (Top Right Bottom Left)
padding: 10px;              /* cả 4 cạnh */
padding: 10px 20px;         /* trên/dưới 10, trái/phải 20 */
padding: 10px 20px 30px;    /* trên 10, trái/phải 20, dưới 30 */
padding: 10px 20px 30px 40px; /* trên, phải, dưới, trái */
margin: 0 auto;            /* căn ngang khi phần tử block có width phù hợp */

/* Thường dùng để dễ kiểm soát kích thước: */
* { box-sizing: border-box; }
Thử thách: tạo 2 card, mỗi card có padding 20px và border 2px. Thêm margin-bottom 16px để tách card. Đổi content-box sang border-box và tự tính chiều rộng trước khi quan sát.
Chủ đề 03 · bố cục một chiều

Flexbox: xếp các phần tử theo một hàng hoặc một cột

Flexbox thích hợp để sắp xếp logo và menu cùng hàng, căn giữa nội dung, hoặc bố trí các ô nhập/nhóm nút theo một chiều.

Flexbox (Flexible Box Layout) là chế độ bố cục CSS. Đặt display: flex lên cha → các con trực tiếp trở thành flex items (mục Flex). Main axis (trục chính) đi theo flex-direction. Cross axis (trục phụ) vuông góc trục chính.

1. Năm thuộc tính cần hiểu

Thuộc tínhĐặt ở đâu?Tác dụng
display: flexChaKích hoạt Flexbox
flex-directionCharow ngang, column dọc
justify-contentChaCăn và phân phối phần không gian dư trên trục chính
align-itemsChaCăn các item trên trục phụ
gapChaTạo khoảng cách giữa các item
flexConĐiều khiển việc item lớn lên/co lại/cơ sở kích thước
Điểm dễ nhầm: justify-content không phải lúc nào cũng căn ngang; nó căn theo TRỤC CHÍNH. Khi flex-direction: column, trục chính đứng dọc. align-items: stretch chỉ kéo giãn nếu kích thước theo trục phụ không bị đặt cố định hoặc có ràng buộc khác.

2. Thực hành Header có logo bên trái, menu bên phải

  1. Viết HTML cho thẻ cha header và hai phần tử con: logo + nav.
  2. Đặt display: flex trên thẻ header để hai con nằm cùng hàng.
  3. Thêm justify-content: space-between để đẩy logo và menu về hai phía (khi còn không gian dư).
  4. Thêm align-items: center để chúng căn giữa theo chiều dọc; gap tạo khoảng cách tối thiểu.
HTML
<header class="site-header">
  <div class="logo">EduShop</div>
  <nav>
    <a href="index.html">Trang chủ</a>
    <a href="login.html">Đăng nhập</a>
  </nav>
</header>
CSS
.site-header {
  display: flex;                 /* kích hoạt Flexbox trên CHA */
  flex-direction: row;           /* xếp con theo hàng ngang */
  justify-content: space-between;/* đẩy logo và menu ra 2 phía */
  align-items: center;           /* căn giữa theo chiều dọc */
  gap: 20px;                     /* khoảng trống tối thiểu */
  padding: 16px 24px;
  background: #153a62;
  color: white;
}
.site-header a { color: white; margin-left: 12px; }

Chủ đề 04 · bố cục hai chiều

CSS Grid: tạo lưới hàng và cột

Grid phù hợp nhất với danh sách danh mục và thẻ sản phẩm trên trang Home khi muốn các ô xếp thành nhiều cột nhất quán.

CSS Grid Layout là bố cục hai chiều (hàng + cột). Đặt display: grid trên cha; các con trực tiếp là grid items. Track là một hàng/cột; gap là khoảng trống giữa các track; fr là đơn vị chia phần không gian khả dụng của lưới (sau khi tính các track/khoảng cách khác).

1. Các khái niệm quan trọng

Thuộc tính/giá trịÝ nghĩaVí dụ
display: gridBật chế độ Grid trên chaDanh sách 6 sản phẩm
grid-template-columnsKhai báo số và kích thước cộtrepeat(3, 1fr)
grid-template-rowsKhai báo hàng khi cần100px 150px
gapKhoảng cách giữa các ô20px
repeat(n, ...)Lặp một mô tả track n lầnrepeat(3, 1fr)
grid-column: span 2Một ô chiếm hai cộtBanner nổi bật trong lưới

2. Dựng danh mục ba cột

  1. Tạo một thẻ cha div class="category-grid".
  2. Đặt 6 thẻ div class="category" bên trong.
  3. Thêm display: grid vào cha. Nếu chỉ thêm dòng này, trình duyệt mặc định chưa tự tạo ba cột như mong muốn.
  4. Thêm grid-template-columns: repeat(3, 1fr) để chia thành ba cột và gap: 20px để tách các ô.
HTML
<div class="category-grid">
  <div class="category">Lập trình</div>
  <div class="category">Robotics</div>
  <div class="category">Thiết kế</div>
  <div class="category">Game</div>
  <div class="category">AI</div>
  <div class="category">Khoa học</div>
</div>
CSS
.category-grid {
  display: grid;                        /* bật Grid cho CHA */
  grid-template-columns: repeat(3, 1fr);/* 3 cột bằng nhau */
  gap: 20px;                            /* cách giữa các ô */
}
.category {
  padding: 18px;
  background: #d9eaff;
  border: 1px solid #2776c1;
  text-align: center;
}

Ảnh mô phỏng hai layout của bài tập

Checklist trước khi tự thực hành

  • Biết phân biệt cha và con: display:flex/grid phải đặt trên cha cần sắp xếp các con trực tiếp.
  • Biết khi nào dùng padding (bên trong) và margin (bên ngoài).
  • Biết tính chiều rộng content-box và border-box.
  • Biết justify-content là trục chính; align-items là trục phụ.
  • Biết tạo Grid 3 cột và thay đổi gap.
  • Không cần JavaScript, kết nối tài khoản, database hoặc thiết kế Responsive.

Hỏi nhanh – mở đáp án sau khi tự trả lời

1. Có 3 thẻ DIV con xếp dọc. Muốn nằm cùng hàng, viết CSS ở đâu?

Thêm display: flex; vào thẻ CHA bao 3 thẻ con, không phải từng thẻ con.

2. Chữ sát viền của card. Dùng margin hay padding?

Dùng padding để tăng khoảng cách từ chữ (content) đến đường viền (border).

3. Trong Flexbox row, muốn hai item tách về hai đầu?

Cha: display: flex; justify-content: space-between;. Cần có không gian dư để hiệu ứng thấy rõ.

4. Muốn 6 card thành 3 cột, dùng thuộc tính nào?

Cha: display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px;.

5. width 200px, padding 10px mỗi bên, border 2px mỗi bên, content-box: rộng ngoài bao nhiêu?

200 + 10×2 + 2×2 = 224px, không tính margin.

Lộ trình thực hành 45–90 phút

Tự tay tạo file Home và Login

  1. Tạo thư mục website-layout, tạo file index.html, login.html, style.css.
  2. Với index.html, dựng header, main, footer. Chưa viết CSS, mở file để nhìn cấu trúc.
  3. Đưa logo và menu vào header. CSS header display:flex; justify-content:space-between; align-items:center.
  4. Trong main thêm Hero, tìm kiếm, danh mục và card sản phẩm. Dùng padding tạo khoảng cách trong từng khu.
  5. Dùng Grid repeat(3,1fr) cho danh mục và card sản phẩm. Chỉ dùng bản desktop (không Media Queries).
  6. Với login.html, tạo form, label, input, button. Dùng Flexbox căn giữa form và Box Model trang trí thẻ form.
  7. Đối chiếu bản minh họa Home/Login bên trên; kiểm tra đường dẫn <link rel="stylesheet" href="style.css">, lưu file và F5.
