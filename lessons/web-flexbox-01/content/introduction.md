# Khám phá CSS Flexbox

Chào mừng bạn đến với bài học tương tác **CSS Flexbox**!

Trong thiết kế giao diện website hiện đại, việc dàn trang các phần tử thẳng hàng, căn giữa, hoặc phân bổ đều khoảng cách luôn là yêu cầu căn bản nhất. **Flexbox (Flexible Box Layout)** sinh ra để giải quyết triệt để vấn đề này.

### Mục tiêu bài học:
1. Hiểu rõ mô hình trục chính (**Main Axis**) và trục phụ (**Cross Axis**).
2. Nắm vững thuộc tính `display: flex` và các thuộc tính căn chỉnh cốt lõi.
3. Thực hành viết code dàn trang thanh điều hướng (Navigation Bar) chuẩn xác.
4. Kiểm thử giao diện tự động bằng bộ Test Runner của trình duyệt.
